Reading the numbers
One run is one estimate. Fold predictions are collapsed before they reach disk, so there are no replicates and nothing here is a distribution. The interval on a mark is the bootstrap CI the pipeline already wrote.
R² is the only cross-target metric. RMSE and MAE carry each target's own units — daltons for molecular weight, pKd for affinity, counts for bonds.
ΔR² subtracts the paired shuffled_ident baseline. That control sits at R² ≈ 0 across the sweep (mean −0.005, sd 0.008), so ΔR² and R² agree closely.
